RxJS Higher Order Mapping Operators

Learn when and why to use switchMap, mergeMap, concatMap and exhaustMap in Angular.

🔄 switchMap

Cancels the previous API request whenever a new value is emitted and subscribes only to the latest request.

Why use it?
  • Prevents unnecessary API calls.
  • Only latest user input matters.
  • Best for Search Autocomplete.
Real Time Example

Google Search, YouTube Search, Product Search, Employee Search.

⚡ mergeMap

Executes every request simultaneously. No request gets cancelled.

Why use it?
  • Multiple requests can run together.
  • Fast execution.
  • Response order doesn't matter.
Real Time Example

Upload multiple images, Send notifications, Fetch multiple user profiles.

📋 concatMap

Executes requests one after another. Waits until the current request finishes.

Why use it?
  • Maintains request order.
  • No request is cancelled.
  • Perfect for sequential operations.
Real Time Example

Save Form Step 1 → Save Step 2 → Save Step 3

🚫 exhaustMap

Ignores all new requests until the current request completes.

Why use it?
  • Prevents duplicate API calls.
  • Avoids double clicking.
  • Only first request is accepted.
Real Time Example

Login Button, Payment Button, Place Order Button.
